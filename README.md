# Spectral-Soft-Sensor-
Repo contains code for spectral soft sensor data analysis 

## File Structure

- **group_work_part1.mlx**  
  Main MATLAB Live Script for Part 1 of the analysis.  


- **group_work_part2.mlx**  
  Main MATLAB Live Script for Part 2 of the analysis.  


- **group_work_part3.mlx**  
  Main MATLAB Live Script for Part 3 of the analysis.  

## Usage

1. Clone or download this repository.
2. Download the Spectral Soft Sensor datasets on the moodle page (both).
3. Ensure that `group_work_part#.mlx`, `data_part_1.csv` and `data_part_2.csv` are in the same folder.  
4. Open `group_work_part#.mlx` in MATLAB.  
5. Run the script to reproduce the analysis results.
